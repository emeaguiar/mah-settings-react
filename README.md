# Mah Settings

## Description

A demo of a settings page using React components available in WordPress

## Installation

1. Clone the repo `git clone git@github.com:emeaguiar/mah-settings-react.git`
2. Move to the cloned folder `cd mah-settings-react`
3. Install dependencies `npm install`
4. Build the plugin `npm run build`
5. Move the contents inside the `build` folder to the `plugins` directory
6. Activate the plugin
7. Select in the required options from the newly created `Mah Settings` options page
